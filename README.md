# Circuit Supply

A responsive, static storefront for a fictional edit of everyday technology.

## Open the site

Open `index.html` directly in a browser, or serve the project directory with any static file server. The site uses plain HTML, CSS, and JavaScript; it has no build step or package dependencies.

## Pages

- `index.html` — storefront home
- `shop.html` — category filters and sorting
- `product.html?id=arc-headphones` — product details (use any product link from the shop)
- `about.html` — brand point of view
- `contact.html` — contact form preview
- `cart.html` — shopping bag saved in browser local storage
- Search from the header or shop collection; save products for later from product cards or the bag

Product images and fonts are loaded from Unsplash and Google Fonts. Contact and checkout are presentation-only and are not connected to backend services.
